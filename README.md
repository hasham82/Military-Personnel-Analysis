# Military-Personnel-Analysis
Interactive Streamlit Web App for analyzing military personnel performance from CSV datasets.
🎖️ Military Personnel Performance Analysis Dashboard

This project is an interactive Streamlit-based analytical dashboard designed to assess and visualize the performance of military personnel across different units. It allows users to upload CSV data, automatically cleans and preprocesses the dataset, generates insightful visualizations, and highlights underperforming units with actionable recommendations.

🚀 Features

📁 CSV Upload

🧹 Automated data cleaning

📊 Interactive visualizations

📋 Unit-wise performance summary

🚨 Underperformance detection

💡 Additional insights

🧾 Required CSV Columns

Personnel_ID

Unit

Training_Score

Mission_Success_Rate

Fatigue_Level

Attendance_Rate

Training_Type

🛠️ Tech Stack

Python

Streamlit

Pandas

NumPy

Matplotlib

Seaborn

streamlit run app.py
